채널별 상세보기

매출 = 결제 완료 · 환불 예약의 (결제 금액 − 환불 금액). 취소했어도 환불하지 않은 금액은 매출로 남습니다. 결제일 기준은 결제일을 적지 않은 예약을 이용일로 셉니다. 홈페이지 이용권은 결제일 기준이며 부분 환불액을 차감하고 테스트 결제와 환불 · 취소 주문은 빠집니다.

페이앱 결제 내역

홈페이지 결제와 판매자센터 직접 결제를 모았습니다. 직접 결제는 소셜팩토리 매출인지 확인한 뒤 합산하세요. 기존 예약에 이미 포함된 결제·메가스팟·주차·테스트는 제외할 수 있습니다.

‘페이앱만 보기’는 기존 예약에 반영된 페이앱 결제도 포함합니다. 전체 매출에는 기존 예약으로 한 번만 합산합니다. 메가스팟·주차·테스트 등 제외한 결제는 집계하지 않습니다. ‘카드결제(온라인)’는 예약에 직접 입력한 결제수단으로 페이앱 전용 분류가 아닙니다.

매출 합산 여부만 바꿉니다. 기존 예약과 같은 결제라면 제외하고 사유에 적어주세요.

이전 내역 가져오기 · 연결 안내

과거 내역은 판매자센터에서 확인한 페이앱 JSON으로 가져옵니다. 같은 결제번호는 중복 저장하지 않습니다. 신규 직접 결제는 판매자센터의 공통 통보 URL을 연결한 시점부터 수신합니다.

토스플레이스 개발자센터의 Open API 앱을 소셜팩토리 운영 매장에 설치한 뒤, 서버 설정에 매장 ID·API 키·웹훅 서명 키를 연결하세요. 프론트 플러그인 앱과 별도입니다.

수신 주소: https://socialfactory.co.kr/api/toss-place/webhook
수신 이벤트: 앱 설치/설치 해제 · 결제 승인/취소

먼저 서명 키를 서버 Secret에 저장하고 매장에 앱을 설치하면 아래에 매장 이름과 Open API 매장 ID가 나타납니다. 실제 소셜팩토리 매장인지 확인한 뒤 TOSS_PLACE_MERCHANT_ID를 연결합니다. 설치 이벤트만으로 매출 수집이 켜지지는 않습니다.

Cloudflare 서버 설정: TOSS_PLACE_MERCHANT_ID · TOSS_PLACE_ACCESS_KEY · TOSS_PLACE_SECRET_KEY · TOSS_PLACE_WEBHOOK_SECRET. 비밀 키는 채팅이나 파일에 넣지 말고 서버 Secret으로 저장합니다.

가져온 결제 · 매출 합산 관리

메가스팟·주차 결제는 선택해 소셜팩토리 매출에서 제외하세요. 원거래는 보관되며 다시 합산할 수 있습니다. ‘확인 필요’는 합산 전 보류된 내역입니다.

상품명은 토스 주문 기준입니다. 분할 결제는 같은 주문 상품이 표시됩니다. 토스에 상품명이 없으면 ‘상품명 없음’으로 표시합니다.

0건 선택

매출 집계에만 적용됩니다. 토스 결제를 취소하거나 환불하지 않습니다. 이용권 자동 중복 제외는 유지됩니다.

‘금액 입력’은 토스 원본 상품명 기준입니다. ‘미작성만 보기’는 직접 입력한 상품명과 메모가 모두 비어 있는 내역만 표시합니다. 둘 중 하나라도 저장하면 이 목록에서 빠집니다. 입력 내용은 상품정보를 다시 불러와도 유지됩니다.

상품명이나 메모 중 필요한 것만 적으세요. 빈칸으로 저장하면 직접 입력한 내용이 지워집니다. 매출 제외 여부는 별도로 선택하세요.

스페이스클라우드 자동 매출 동기화

연결 코드는 크롬 도구 설정 화면에 한 번 입력합니다. 로그인 비밀번호를 입력하지 마세요. 환불 증가분은 자동 갱신되며, 상충 자료와 정산 후 별도 취소금액은 확인 대상으로 남습니다.

파일로 가져오기

스페이스클라우드 결제내역 일괄 가져오기

자동 동기화가 멈추거나 이전 내역을 보충할 때 사용하는 수동 가져오기입니다. 정산 전 결제는 크롬 수집 도구로 저장한 JSON, 정산 완료 건은 호스트센터의 원본 XLSX를 선택하세요. 정산 전 결제 수집 방법. 파일 선택 후 미리보기를 표시하며, 같은 예약번호는 한 번만 합산합니다. 매출은 결제금액 − 취소금액이며, 수수료 차감 후 정산금액과 다릅니다.

예약번호가 같으면 중복 합산하지 않습니다. 기존 기록과 금액이 다른 건은 자동으로 덮어쓰지 않습니다. 엑셀에는 룸과 이용 시각이 없어, 캘린더로 확인되지 않은 건은 공간별 매출에서 ‘기타’로 표시합니다. 여러 날짜 예약은 이용시작일에 매출을 합산합니다.

    ‘발송 접수’는 업체가 요청을 받은 상태입니다. 실제 도착은 알리고 전송내역에서 확인합니다. 결과 미확인 건은 자동 재발송하지 않습니다.

    주문번호종류결과시각 · 메시지 번호

    주문 · 결제

    홈페이지 홈페이지 온라인 결제 내역입니다. 승인되면 고객·이용권에도 자동 등록되고, 페이앱 취소·환불 결과가 함께 반영됩니다.

    주문번호 · 시각상태상품금액구매자결제이용 시작일 · 요청운영 메모
    환불은 어떻게 처리하나요?
    1. 고객이 주문번호와 함께 환불을 요청하면 상태를 환불 요청으로 바꿔 둡니다.
    2. 페이앱 판매자센터 → 결제현황에서 해당 주문의 결제 건을 찾아 전체 취소 또는 부분 취소합니다. 규정(7일 안 전액, 이후 90%, 정기권 일할 차감)에 맞는 금액으로 취소해 주세요.
    3. 취소 통보를 받으면 전체·부분 환불 금액과 주문 상태, 매출에 자동 반영됩니다. 실제 취소는 페이앱 판매자센터에서 처리하고, 반영이 늦어지면 검색 · 새로고침을 눌러 확인해 주세요.

    회원

    이메일로 가입한 회원 목록입니다. 비밀번호를 잊은 회원은 본인 확인 후 임시 비밀번호를 발급해 전달해 주세요.

    번호가입이름 · 연락처소식 수신상태문의최근 로그인관리

    임시 비밀번호는 발급 직후 한 번만 보입니다. 회원은 로그인 뒤 마이페이지에서 새 비밀번호로 바꾸게 됩니다.

    예약 신청 · 페이앱

    공간대관은 외부 일정을 확인하고 시간을 확보한 뒤 결제를 안내합니다. 독립사무실은 상담한 조건으로 청구합니다.

    클라우드 연동

    예약 탭을 열면 로그인 저장 여부와 작업 상태를 확인합니다.

    노트북을 꺼도 클라우드에서 예약을 처리합니다. 정해 둔 사용 한도에 도달하면 추가 실행을 멈춥니다. 호스트 연결과 일정 조회 설정을 함께 확인합니다. 로그인 화면을 사용하는 경우 원래의 5분 유효시간을 유지합니다.

    로그인 화면 열기 ↗

    비밀번호와 인증번호는 새 로그인 화면에 직접 입력하며, 채팅에 보내지 마세요.

    공간대관 신청

    스페이스클라우드 시간 확보와 결제 상태를 함께 확인합니다. 취소·환불이 확인된 예약만 해당 예약이 확보한 시간을 해제합니다. 처리 결과가 불확실한 건은 결제를 보류하고 확인할 때까지 시간을 유지합니다.

    독립사무실 상담 후 청구

    문자는 자동 발송하지 않습니다. 생성된 링크를 상담 고객에게 전달해 주세요. 한 상담 건에서 같은 청구를 반복 발급하지 않습니다.

    상품

    홈페이지에서 판매 중인 이용권과 누적 판매량입니다. (테스트 결제 제외)

    상품 이름 · 가격 · 설명을 바꾸려면 GitHub 저장소의 functions/_lib/products.js 파일을 고치고 Commit 하면 됩니다. 홈페이지 상품 페이지와 결제 금액 검증이 모두 이 파일 하나를 씁니다. 룸 대관 요금은 js/site-config.js 의 pricing 이고, 예약 등록 창의 요금표 계산도 같은 값을 씁니다.

    설정 상태

    Cloudflare Pages 설정값과 데이터베이스 표가 준비되었는지 확인합니다. 값 자체는 보이지 않고 있는지 없는지만 봅니다.

    예약 안내 모니터

    아래 주소를 모니터 브라우저에서 열면 바로 예약 안내가 표시됩니다. 관리자 로그인이나 기기 연결 링크 발급은 필요하지 않습니다. 예약자명은 마스킹하며 연락처·결제금액·내부 메모는 표시하지 않습니다.

    예약 안내 화면 열기 ↗예시 화면 보기 ↗

    검색 제외 태그를 적용하고 사이트맵·홈페이지 메뉴에서 제외한 화면입니다. 주소를 아는 사람은 조회할 수 있습니다.

    스페이스클라우드 예약 연결

    각 룸의 캘린더 내보내기 주소를 저장하면 예약 시간표에 자동으로 표시합니다. 비워 둔 룸은 기존 연결을 유지합니다. 캘린더에는 연락처 · 인원 · 금액이 없지만, 같은 예약번호의 결제내역이 자동 수집되면 예약 상세에 금액을 표시합니다. 매출은 결제내역에서 한 번만 합산합니다.
