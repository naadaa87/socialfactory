관리자 로그인

Cloudflare Pages 설정에 넣어 둔 ADMIN_KEY 값을 입력해 주세요. 키는 이 브라우저 탭에만 보관되며 주소창에 남지 않습니다.

문의 · 회원 · 주문 데이터는 Cloudflare D1 에 저장됩니다. 결제 취소(환불)는 KG이니시스 가맹점관리자에서 처리하고 여기에는 결과를 기록합니다.

문의

홈페이지 문의 폼으로 들어온 내용입니다. 상태를 바꾸면 회원은 마이페이지에서 바로 볼 수 있습니다.

접수번호접수 시각상태목적 · 공간이름 · 연락처일정 · 인원내용알림

주문 · 결제

이용권 온라인 결제 내역입니다. 입실 처리는 '이용 완료', 환불은 가맹점관리자에서 취소한 뒤 '환불 완료'로 바꿔 주세요.

주문번호 · 시각상태상품금액구매자결제이용 시작일 · 요청운영 메모
환불은 어떻게 처리하나요?
  1. 고객이 카카오톡 · 이메일 · 문의 폼으로 주문번호와 함께 환불을 요청하면, 이 표에서 상태를 환불 요청으로 바꿔 둡니다.
  2. KG이니시스 가맹점관리자(iniweb.inicis.com) → 거래내역 조회에서 같은 주문번호(TID)를 찾아 전체 취소 또는 부분 취소합니다. 규정(7일 안 전액, 이후 90%, 정기권 일할 차감)에 맞는 금액으로 취소해 주세요.
  3. 취소가 끝나면 상태를 환불 완료로 바꾸고 운영 메모에 취소 금액을 적어 둡니다. 회원 주문이면 마이페이지에도 같은 상태가 보입니다.

회원

이메일로 가입한 회원 목록입니다. 비밀번호를 잊은 회원은 본인 확인 후 임시 비밀번호를 발급해 전달해 주세요.

번호가입이름 · 연락처소식 수신상태문의최근 로그인관리

임시 비밀번호는 발급 직후 한 번만 보입니다. 회원은 로그인 뒤 마이페이지에서 새 비밀번호로 바꾸게 됩니다.

상품

홈페이지에서 판매 중인 이용권과 누적 판매량입니다.

상품 이름 · 가격 · 설명을 바꾸려면 GitHub 저장소의 functions/_lib/products.js 파일을 수정하고 Commit 하면 됩니다. 홈페이지 상품 페이지와 결제 금액 검증이 모두 이 파일 하나를 쓰기 때문에, 바꾼 뒤에는 상품 페이지(/product/상품id)가 새 값으로 보이는지 한 번 확인해 주세요. 가격을 0원이나 빈값으로 두면 결제 심사 조건에 어긋납니다.
