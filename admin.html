관리자 화면에서 등록한 예약의 결제 금액을 결제수단별로 모았습니다. 결제 전 예약은 매출에 넣지 않고 미수금으로 따로 보여 줍니다.

채널별 상세보기

매출 = 결제 완료 · 환불 예약의 (결제 금액 − 환불 금액). 취소했어도 환불하지 않은 금액은 매출로 남습니다. 결제일 기준은 결제일을 적지 않은 예약을 이용일로 셉니다. 홈페이지 이용권은 KG이니시스 결제일 기준이며 테스트 결제와 환불 · 취소 주문은 빠집니다.

스페이스클라우드 자동 매출 동기화

연결된 PC의 크롬에서 15분마다 수집합니다. 매출은 로그인한 모든 관리자에게 동일하게 표시됩니다. PC 절전·크롬 종료·호스트센터 로그인 만료 시 수집이 멈춥니다.

연결 상태 확인 중…

연결 코드는 크롬 도구 설정 화면에 한 번 입력합니다. 로그인 비밀번호를 입력하지 마세요. 환불 증가분은 자동 갱신되며, 상충 자료와 정산 후 별도 취소금액은 확인 대상으로 남습니다.

파일로 가져오기

스페이스클라우드 결제내역 일괄 가져오기

자동 동기화가 멈추거나 이전 내역을 보충할 때 사용하는 수동 가져오기입니다. 정산 전 결제는 크롬 수집 도구로 저장한 JSON, 정산 완료 건은 호스트센터의 원본 XLSX를 선택하세요. 정산 전 결제 수집 방법. 파일 선택 후 미리보기를 표시하며, 같은 예약번호는 한 번만 합산합니다. 매출은 결제금액 − 취소금액이며, 수수료 차감 후 정산금액과 다릅니다.

예약번호가 같으면 중복 합산하지 않습니다. 기존 기록과 금액이 다른 건은 자동으로 덮어쓰지 않습니다. 엑셀에는 룸과 이용 시각이 없어, 캘린더로 확인되지 않은 건은 공간별 매출에서 ‘기타’로 표시합니다. 여러 날짜 예약은 이용시작일에 매출을 합산합니다.

문의

홈페이지 문의 폼으로 들어온 내용입니다. 상태를 바꾸면 회원은 마이페이지에서 바로 볼 수 있고, 예약 등록을 누르면 이름 · 연락처 · 공간이 채워진 예약 등록 창이 열립니다.

주문번호 · 시각상태상품금액구매자결제이용 시작일 · 요청운영 메모
환불은 어떻게 처리하나요?
  1. 고객이 주문번호와 함께 환불을 요청하면 상태를 환불 요청으로 바꿔 둡니다.
  2. KG이니시스 가맹점관리자(iniweb.inicis.com) → 거래내역 조회에서 같은 주문번호(TID)를 찾아 전체 취소 또는 부분 취소합니다. 규정(7일 안 전액, 이후 90%, 정기권 일할 차감)에 맞는 금액으로 취소해 주세요.
  3. 취소가 끝나면 상태를 환불 완료로 바꾸고 운영 메모에 취소 금액을 적어 둡니다.
