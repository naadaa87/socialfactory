스페이스클라우드 자동 매출 동기화

크롬 도구 2.0을 관리자에 한 번 연결하면, PC와 크롬이 실행되는 동안 15분마다 정산 전·완료 내역을 읽고 매출에 직접 전송합니다. 매번 파일을 올릴 필요가 없습니다.

최초 한 번 연결

  1. 크롬 도구 2.0 내려받기 후 압축을 풉니다. 크롬의 chrome://extensions에서 기존 도구를 삭제하고 개발자 모드 → ‘압축해제된 확장 프로그램을 로드합니다’에서 새 폴더를 선택합니다.
  2. 이 버전은 호스트센터·소셜팩토리 두 사이트 접근, 15분 주기 실행, 알림 권한을 사용합니다. 다른 사이트에 대한 접근 권한은 요청하지 않습니다.
  3. 소셜팩토리 관리자 → 매출 → 크롬 연결 코드 발급을 누릅니다. 이 코드는 10분간 유효하며 한 번만 사용할 수 있습니다.
  4. 관리자 페이지를 연 상태에서 크롬 도구 아이콘을 누르면 설정이 열립니다. 연결 코드와 결제 조회 시작일을 입력한 뒤 ‘연결하고 자동 동기화 시작’을 누릅니다. 기본 조회 시작일은 2020-01-01이며 이전 결제는 제외됩니다. 최대 200페이지·5,000건입니다.
  5. 관리자에서 마지막 성공 시각과 처리 결과를 확인합니다. 모든 관리자는 같은 서버 매출 내역을 봅니다.

운영 중 확인할 것

PC 절전·크롬 종료 시 수집이 멈추고, 다시 실행되면 재시도합니다. 브라우저가 켜져 있어도 로그인 만료 시에는 호스트센터에 다시 로그인해야 합니다. 크롬 알림 허용이 필요하며 관리자에도 ‘재로그인 필요’를 표시합니다. 마지막 성공 후 45분이 지나면 관리자에서 미동기화 경고를 보여 줍니다.

예약번호가 같으면 한 번만 합산합니다. 부분·전액 환불 증가분은 기존 기록을 갱신합니다. 결제금액·날짜 상충, 환불금액 감소, 정산 완료 화면의 별도 ‘정산후 취소금액’은 잘못 차감하지 않도록 관리자 확인 대상으로 표시합니다. 조회 결과에 없는 예약을 삭제하거나 0원으로 만들지 않습니다.

로그인 비밀번호·쿠키·고객 이름·전화번호는 서버로 전송하지 않습니다. 매출 동기화 전용 연결키를 크롬에 보관하며 관리자 전체 비밀번호는 저장하지 않습니다. 연결키 유효기간은 180일이며 관리자에서 언제든 연결을 해제할 수 있습니다.

중지·재개와 수동 백업

크롬 도구 설정에서 일시 중지·재개·지금 확인을 사용할 수 있습니다. 관리자 ‘자동 동기화 연결 해제’는 해당 PC의 전용 키를 무효화합니다. 자동 실행을 중지한 상태에서는 호스트센터 화면에서 수동 수집하여 JSON을 가져오는 기존 방법도 유지됩니다.

사이트 화면이 바뀌거나 날짜·금액을 확인하지 못하면 자동 수집을 중단하고 알립니다. 여러 날짜 또는 자정 경계를 넘는 예약 표시는 현재 확인이 필요합니다. 최초 실제 설치·연결 후 15분 주기 실행과 로그인 만료 알림을 검증해야 합니다.
