정산 전 결제도 한 번에 가져오기

크롬에 로그인된 호스트센터의 정산 예정 상세내역을 읽어 JSON 파일로 저장합니다. 비밀번호를 저장하지 않으며, 수집 파일에는 고객 이름·전화번호가 포함되지 않습니다.

최초 한 번 설치

  1. 크롬 수집 도구 내려받기 후 압축을 풉니다.
  2. 크롬의 chrome://extensions를 열고 개발자 모드를 켭니다. ‘압축해제된 확장 프로그램을 로드합니다’에서 풀어 놓은 폴더를 선택합니다.
  3. 이 도구는 ‘클릭한 탭 읽기/동작’과 수집 중 임시 저장 권한을 사용합니다. 수집을 시작한 호스트센터의 정산 예정 화면만 처리하며, 금액을 외부 서버로 전송하지 않습니다.

결제내역 가져오기

  1. 호스트센터 정산 예정에 기존 호스트 계정으로 로그인합니다.
  2. 기간 기준을 ‘결제일’로, 조회 기간과 공간을 선택하고 ‘조회’를 누릅니다.
  3. 크롬 확장 프로그램에서 ‘소셜팩토리 스페이스클라우드 결제 수집’을 누릅니다. 조회 결과의 첫 페이지부터 다음 페이지까지 자동으로 이동합니다. 완료 안내가 뜰 때까지 탭을 조작하지 마세요.
  4. 저장된 spacecloud-payments-날짜.json 파일을 관리자 → 매출에서 선택합니다. 미리보기의 날짜와 금액을 확인하고 ‘위 내역을 매출에 반영’을 누릅니다.

관리자 매출은 기본으로 결제일 기준을 보여 줍니다. 정산 예정에서 가져온 건이 나중에 정산 완료 엑셀에 포함돼도 같은 예약번호는 중복 합산하지 않습니다. 취소·환불로 기존 기록과 금액이 달라진 경우 자동 덮어쓰지 않고 확인 대상으로 표시합니다.

호스트센터의 화면이 바뀌거나 읽지 못하는 날짜 형식이 있으면 오류를 표시하고 파일 저장을 중단합니다. 여러 날짜 또는 자정 경계를 넘는 예약은 현재 수집 도구에서 확인이 필요합니다. 로그인 유지가 필요한 수동 실행 도구이며, 24시간 서버 자동 동기화 기능은 아닙니다.
