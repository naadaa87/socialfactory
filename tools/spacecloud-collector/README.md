# 스페이스클라우드 결제 수집 도구

설치는 홈페이지 `/spacecloud-import-help.html`의 안내를 따릅니다. 관리자와 연결하면 크롬이 실행 중일 때 15분마다 **정산 예정·완료** 화면을 읽고 매출 서버에 직접 전송합니다. 수동으로 도구를 누르는 기능은 백업용으로 남아 있습니다.

실제 화면에서 확인된 표 머리글과 상세 항목만 사용합니다. 내부 API 호출, 로그인 쿠키/토큰 읽기, 수수료를 통한 금액 역산은 하지 않습니다. 고객 이름과 전화번호는 수집 결과에 포함하지 않습니다. 작업 중 모인 금액은 chrome.storage.session에만 잠시 저장하며 완료/오류 시 제거합니다. 오류 시 일부만 모인 내역은 전송하지 않습니다. 수동 수집 때는 JSON 파일 미리보기를 확인합니다.

화면 구조 변경, 조회 조건 변경, 동일 예약의 상충 값, 날짜 또는 금액 읽기 실패는 수집을 중단합니다. 여러 날짜/야간 경계를 넘는 예약은 추정하지 않고 중단합니다. 취소금액이 결제금액보다 크거나 가져오기 기록과 다른 금액은 관리자에서 차단됩니다. 정산 전→정산 후 전환은 예약번호가 같으면 매출을 추가하지 않습니다.

## 1.0.1 수정

동일 예약을 객체 전체 문자열로 비교하던 코드를 실제 예약번호·날짜·금액 필드별 비교로 바꿨습니다. 같은 값의 항목 순서가 달라도 오류로 판단하지 않습니다. 다음 페이지를 읽기 전 예약번호 목록이 이전 페이지와 달라지고 600ms 이상 안정적인지 확인하며, 수집 중 예약 행이 교체되면 저장을 중단합니다. 실제 금액이 상충하는 경우의 차단은 유지합니다.

## 1.0.2 수정

실제 호스트센터에서 주소만 page=2로 바꾸면 1페이지 표가 남는 현상을 확인했습니다. 페이지 이동은 호스트센터의 실제 페이지 링크 클릭으로 처리하며 SPA 이동 후 같은 실행에서 이어서 수집합니다. 새 문서로 이동한 경우에만 onUpdated에서 재개합니다. 원본 크롬 메시지의 URL이 SPA 초기 URL일 수 있으므로 매 수집 결과에 현재 화면 주소를 함께 보내 페이지를 확인합니다. 실제 사이트에서는 기존 도구 1.0.1 설치본으로 하드 내비게이션 오류가 확인됐고, 수정본 1.0.2 전체 실행은 설치 갱신 후 확인이 필요합니다.

## 2.0.0 자동 동기화

호스트센터/관리자 두 호스트에만 지속 권한을 요청합니다. alarms(15분), notifications, scripting, storage를 사용합니다. 설정 페이지에서 관리자 일회용 연결 코드로 동기화 전용 키를 발급받습니다. admin 전체 키/로그인 쿠키를 복사하지 않습니다. 크롬 storage.local은 TRUSTED_CONTEXTS만 접근하도록 제한하며 키의 원문은 옵션/콘텐츠 응답에 반환하지 않습니다. OS 차원의 암호화 저장소를 사용하는 것은 아니므로 PC 계정 보안이 필요합니다. 서버에는 키 해시만 보관하고 180일 만료, 수동 해제, 관리자 키 변경 시 무효화를 지원합니다.

자동 실행은 별도 비활성 탭을 생성하여 UI의 결제일·공간·시작일·종료일을 설정하고 정산 예정→완료 전체 페이지를 수집합니다. 날짜 입력은 실제 달력의 월 이동·날짜 클릭을 사용합니다. 내부 API, 네트워크 가로채기, 비공개 앱 상태 조회를 하지 않습니다. 초기 시작일은 2020-01-01이며 이보다 이전 결제는 범위 밖입니다. 최대 200페이지/5,000건이고 10분 이상 오래된 스냅샷은 서버가 거부합니다. 다음 주기 재시도는 중복을 만들지 않습니다. PC 절전/브라우저 종료 동안에는 수집하지 못합니다.

직접 전송은 고정된 소셜팩토리 서버에만 합니다. 콘텐츠 스크립트가 임의 URL로 요청할 수 없고, 설정/토큰 처리 메시지는 패키지의 options.html 발신자만 허용합니다. 정산 전→후 이동 중 같은 예약은 한 건으로 합치며 취소금액은 큰 쪽을 유지합니다. 실제 결제금액·날짜가 상충하면 부분 자료를 전송하지 않습니다. 일반 환불 증가는 업데이트, 감소/결제정보 변경/정산 후 별도 취소금액은 review 기록으로 남깁니다. 이 특수 경우를 자동으로 해석해 원금을 덮어쓰지 않습니다.

성공한 뒤 도구가 만든 탭만 닫습니다. 오류/로그인 만료 시 서버에 상태를 남기고 배지/크롬 알림을 표시합니다(동일 오류는 반복 알림 억제). 관리자 화면은 마지막 시도/성공/연결 만료/45분 미동기화 상태를 표시합니다. Chrome 알림은 OS에서 허용되어 있어야 합니다. 사이트 재로그인은 사용자 직접 진행입니다.

검증은 Node 테스트와 로컬 Cloudflare D1, 모의 브라우저 전체 흐름까지입니다. 설치본 실제 주기 실행·특수 날짜·알림은 배포/설치 승인 후 확인합니다.

## 2.0.1 수정

호스트센터가 페이지를 새로 여는 순간 이전 프레임이 제거되어 코드 삽입이 실패하면, 새 프레임이 준비된 뒤 다시 시도합니다. 연결 버튼은 요청 처리 중 비활성화하고, 연결된 상태에서 같은 일회용 코드를 실수로 다시 보내지 않도록 합니다. 기존 2.0.0 설치본을 삭제하고 재설치하면 로컬 연결 키가 사라지므로 새 연결 코드가 필요합니다.
