# 정산 전 결제 수집 도구

설치는 홈페이지 `/spacecloud-import-help.html`의 안내를 따릅니다. 개발자 모드로 이 폴더를 로드하고 기존 호스트센터의 **정산 예정** 화면에서 도구를 클릭합니다. 클릭한 탭의 현재 조회 조건을 유지하며 첫 페이지부터 최대 100페이지/5,000건을 읽습니다.

실제 화면에서 확인된 표 머리글과 상세 항목만 사용합니다. 내부 API 호출, 로그인 쿠키/토큰 읽기, 수수료를 통한 금액 역산은 하지 않습니다. 고객 이름과 전화번호는 결과 파일에 포함하지 않습니다. 작업 중 모인 금액은 chrome.storage.session에만 잠시 저장하며 완료/오류 시 제거합니다. 오류 시 일부만 모인 파일은 저장하지 않습니다. 관리자에 반영하기 전 JSON 미리보기를 확인합니다.

화면 구조 변경, 조회 조건 변경, 동일 예약의 상충 값, 날짜 또는 금액 읽기 실패는 수집을 중단합니다. 여러 날짜/야간 경계를 넘는 예약은 추정하지 않고 중단합니다. 취소금액이 결제금액보다 크거나 가져오기 기록과 다른 금액은 관리자에서 차단됩니다. 정산 전→정산 후 전환은 예약번호가 같으면 매출을 추가하지 않습니다.

## 1.0.1 수정

동일 예약을 객체 전체 문자열로 비교하던 코드를 실제 예약번호·날짜·금액 필드별 비교로 바꿨습니다. 같은 값의 항목 순서가 달라도 오류로 판단하지 않습니다. 다음 페이지를 읽기 전 예약번호 목록이 이전 페이지와 달라지고 600ms 이상 안정적인지 확인하며, 수집 중 예약 행이 교체되면 저장을 중단합니다. 실제 금액이 상충하는 경우의 차단은 유지합니다.
